# KCF ROI Tracking Demo v0.1.0

Raspberry Pi Zero 2 W、OV5647カメラ、SG90パン・チルトジンバルによる、手動ROI選択型KCF追跡のデモです。

## 添付ファイル

- `gimbal-kcf-roi-browser-demo-v0.1.0.mp4`: PCブラウザーで対象領域を選ぶ画面
- `gimbal-kcf-servo-demo-v0.1.0.mp4`: 追跡中のジンバル動作

## 注意

- この版は、YOLOなどによる自動物体検出を使いません。
- ROIはPCブラウザーから手動で選択します。
- KCFの追跡精度、サーボの反応、カメラの設置条件は環境に依存します。
- 安全上の注意は[SAFETY.md](../SAFETY.md)を参照してください。
