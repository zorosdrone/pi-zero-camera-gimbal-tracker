# Release配布用メディア

このフォルダのMP4はGitで追跡せず、`v0.1.0-kcf-demo` Releaseの添付ファイルとして配布します。

| Release asset | 内容 |
|---|---|
| `gimbal-kcf-roi-browser-demo-v0.1.0.mp4` | PCブラウザーでROIを選択し、KCF追跡を開始する画面 |
| `gimbal-kcf-servo-demo-v0.1.0.mp4` | 追跡中心の変化に応じてSG90ジンバルが動く様子 |

公開時は[リリース公開スクリプト](../scripts/publish-release.ps1)を使うか、GitHubのRelease画面で上の2ファイルを同じタグへ添付します。リリースノートは[release-notes-v0.1.0-kcf-demo.md](release-notes-v0.1.0-kcf-demo.md)です。

追加前に、撮影対象、背景、音声、画面、メタデータ、第三者著作物を確認してください。
